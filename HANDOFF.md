Пользователю уже сказано один раз, повторять не нужно:

1. «Раскраска как пробки» спорит с WCAG 2.1 AA: красный и зелёный нельзя различать только цветом. Решение не меняется, добавляется второй признак — штрих линии и подпись.

- Прочие дорожки (`footway` без уточнения, кампус, парки) — 24,2 км в `extended`, `lit` размечен на 12%, и только 20% лежит в 15 м от улицы. Они честно останутся в основном серыми.
- **Протягивание `lit=yes` по названию улицы работает:** доля неразмеченной длины улиц падает с 57,8% до 34,1% (`extended`) и с 47,2% до 35,6% (`compact`). Противоречий «yes и no на одной улице» нет ни одного; проверка с исключением по одному пути — 183 из 183 совпали. Оговорка: `lit=no` на улицах нет, проверялось только «yes».
- `highway=street_lamp`: 2–4 точки на участок. Источник бесполезен.
- Где `lit` размечен плотно: коридор бульвара Vasile Pârvan (70–100%). Где пусто: юг между Mihai Viteazu и Strada Cluj (13%).
- У автобусных остановок `Complexul Studențesc` стоит `lit=no` на узле остановки. Это про навес, а не про улицу — как свидетельство не использовать.
- **Не измерено:** длины отрезков графа (T3) и безопасный радиус привязки (T4).

### 4.3 Mapillary (по официальной документации, без живых вызовов)

- Класс фонаря: `object--street-light`. Точка появляется, только если объект найден минимум на трёх снимках. Оценки достоверности у точки нет.
- **Проще всего векторные тайлы z14.** На модельный bbox четыре тайла: x 9157–9158, y 5845–5846.
  - Фонари: `https://tiles.mapillary.com/maps/vtp/mly_map_feature_point/2/14/{x}/{y}?access_token=TOKEN`, слой `point`, фильтр `value == "object--street-light"`, поля `id`, `first_seen_at`, `last_seen_at` (миллисекунды).
  - Покрытие съёмки: `https://tiles.mapillary.com/maps/vtp/mly1_public/2/14/{x}/{y}?access_token=TOKEN`, слой `image` с `captured_at`. Есть вариант `mly1_computed_public` с исправленными позициями.
- Альтернатива без декодера тайлов: `GET https://graph.mapillary.com/map_features?bbox=minLon,minLat,maxLon,maxLat&object_values=object--street-light&fields=id,geometry,first_seen_at,last_seen_at&limit=2000`. Пагинации нет, bbox меньше 0,01 градуса; при 2000 строках делить ячейку.
- **Честность:** «не снято» (нет снимков рядом) — нет информации. «Снято, фонарь не найден» — только слабое отрицательное свидетельство.
- Токен: войти на mapillary.com, открыть `mapillary.com/dashboard/developers`, Register Application, скопировать Client Token вида `MLY|…|…`. Шаг самообслуживания; о цене и сроке в документации ничего не сказано.
- Без кода: в веб-приложении Map data → Street Light → Download даёт GeoJSON фонарей. Покрытие так не выгрузить.
- **Лицензия:** обязательны логотип Mapillary и ссылка на сайт. Сырую выгрузку в публичный репозиторий не коммитить — коммитить скрипт выгрузки.
- Точность точек около 2 м, полнота 72–88% — по одному докладу State of the Map 2022, не из официальных документов.

Полный рецепт вызовов — в `handoff/results/source-facts-journal.jsonl`, поле `recipe` агента `mapillary-docs`.

Зелёный — две независимые семьи и нет активного отрицания. Жёлтый — одна семья либо только косвенное. Красный — `lit=no` на самом пути либо свежая открытая жалоба «темно в районе». Серый — ничего | Объяснимо по нажатию; альтернативы — калибровка весов по `lit` и ML — предложить как варианты |
| 2. Привязка точек | По расстоянию до ближайшего отрезка. Радиус выбрать после T4; 50 м из брифа, вероятно, слишком широк для этой сетки улиц. `strada` — только для разрешения спора на перекрёстке | Координаты есть у 96% жалоб; `strada` стоит запроса на каждую |

| 6. Время суток | В подпроекте 1 нет | Ждёт ответа на вопрос 1 |
| 7. Единица карты | Ребро упрощённого ненаправленного графа osmnx, вся пешеходная и велосеть. `segment_id = "{u}-{v}-{key}"` при `u < v`, плюс список `osm_way_ids` и класс пути. Тротуары в 15 м от улицы наследуют её свидетельства как косвенные | T5; длины рёбер (T3) ещё не измерены |

Следствие, которое надо сказать пользователю: порог «серого меньше трети длины» на улицах достижим только на грани — 34–36% серого после протягивания по названию, дальше всё зависит от жалоб и Mapillary. Для всей сети с парковыми дорожками он недостижим, и это честный результат, а не провал.

Адаптер каждого источника выдаёт записи одного формата: `source`, `kind`, `polarity`, `geometry`, `observed_at`, `source_ref`. Реестр фонарей города подключается ещё одним адаптером.
