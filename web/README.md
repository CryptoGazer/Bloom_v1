# Страница города (пункт 3 плана)

Добавлено 14.11.2026. Главная страница продукта: университетский район и центр Тимишоары (`config/area.geojson`), все данные берутся с бэкенда (`backend/`), в браузере ничего не считается.

Язык по умолчанию румынский; английский — кнопками RO / EN вверху панели или параметром `?lang=ro|en`. Выбор запоминается в браузере. Румынские формулировки стоит показать носителю языка.

## Как открыть

```bash
./scripts/mac/lightmap.sh api
```

Открыть http://localhost:8001/

Это тот же адрес, что и у API. Открыть файл `web/index.html` напрямую нельзя: странице нужен сервер.

## Версия для телефона: bezna, «Тихий свет» (`web/m/`, адрес `/m/`)

Добавлено 15.11.2026 по дизайну с холста Claude Design «Traseu de noapte — redesign». Тёмная тема. Маршрут — белая обёртка; где улица не подтверждённо освещена, внутри неё тёмный канал и цветное ядро со своим рисунком: «вероятно» жёлтое пунктиром, «нет данных» серое точками, «сообщали, что темно» красное штрих-пунктиром и красный знак ◇!. Альтернатива — серая обёртка тоньше. Цвет никогда не единственный признак. На телефоне занимает весь экран, на компьютере это колонка шириной до 430 px. Тот же бэкенд и те же данные, что у страницы выше. Старая страница на `/` пока не тронута.

| Экран | Что делает |
|---|---|
| Старт | Запрос своими словами (Gemini, если на сервере есть ключ): строка и микрофон над полями; режим запроса с примерами, запись 10 с, ожидание до 20 с, карточка «Am înțeles» с метками «din cerere» в полях, «Modifică cererea», отдельные сообщения для «не по теме», «непонятно», «слишком много запросов», «сервис недоступен», «микрофон запрещён», «тишина». Ниже поля A и B, способ передвижения, кнопка круговой прогулки, меню языка RO / EN (страница перезагружается на том же экране, без повтора анимации). На карте едва заметная сеть освещённости и граница зоны; подпись границы и «Despre date» — в легенде |
| Поиск | Подсказки из `/api/geocode` с расстоянием от A; «поставить точку на карте» |
| Варианты | Две карточки: самый быстрый и более освещённый. Анимация один раз на новый расчёт: быстрый рисуется светящимся следом, потом его ветка изгибается в более освещённую (0,9 + 0,25 + 0,8 с; при `prefers-reduced-motion` сразу итог; касание карточки во время анимации — сразу итог). Касание участка на карте — источники и даты |
| Подробности | Полоса света по пути, «почему такой цвет» с источниками, признаки жизни с номерами на карте |
| Пешком + транспорт | Время выхода на двух барабанах с инерцией (касание — нативная прокрутка с привязкой к строке, мышь — перетаскивание с броском, стрелки и PageUp/PageDown; подпись «azi / mâine» по тому же правилу, что на сервере), шкала поездки, живая карточка рейса (LIVE с пятью делениями свежести, «УСТАРЕЛО», «ORAR»), шаги, последний рейс |
| На остановке | Крупное «прибудет через N мин» от живых данных, возраст наблюдения и запроса, тикают каждую секунду |
| Навигатор («Pornește») | Следует за GPS: следующий манёвр по смене названия улицы, предупреждение о тёмном участке впереди с «Ocolește», уход с маршрута, оставшийся свет. Голос: переключатель рядом с «Pornește» и в самом навигаторе, выбор запоминается; на румынском и английском говорит голос ElevenLabs (`/api/speak`), при сбое — голос телефона на выбранном языке (`docs/voice.md`). Без GPS или с `?sim=1` — симуляция движения (в 6 раз быстрее пешехода, с пометкой «SIMULARE»), для показа на ноутбуке |

Файлы: `web/m/index.html` (токены и стили), `web/m/m.js` (логика), `web/m/nav.js` (навигатор без браузера: путь, повороты, где телефон на маршруте, прибытие; тесты `node --test web/m/nav.test.cjs`), `web/m/texts.js` (тексты RO/EN поверх `web/i18n.js`). Шрифты Inter, Inter Tight, JetBrains Mono — с Google Fonts.

## Что на странице

- **Граница области** — синий пунктир. Вне неё маршрут не строится: сервер ответит, что точка вне области карты.
- **Запрос своими словами:** если в `.env` настроен `GEMINI_API_KEY`, над адресами появляется поле, которое понимает текст и голос на RO / EN / RU. Gemini только извлекает параметры маршрута; нерелевантные вопросы отсекаются, места проверяются по локальному индексу. Кнопка микрофона видна только в secure context (HTTPS или localhost). Под формой явно указано, что текст или запись отправляется Google Gemini и не хранится нашим сервером.
- **Отдалённо (зум меньше 13):** вместо улиц — подпись с долей улиц и тротуаров области, по которым есть данные об освещении.
- **Приближенно:** улицы и тротуары окрашены по освещённости. Сервер отдаёт только то, что видно на экране.
- **Пешком, на велосипеде или пешком + транспорт:** кнопки под полями адреса; маршрут пересчитывается сразу, режим сохраняется в ссылке (`m=bike`, `m=transit`). Для транспорта — поле «время выхода» (пусто = сейчас) и карточка поездки: шаги, последний рейс; линия транспорта рисуется цветом линии, пешие куски — по освещённости.
- **Транспорт в реальном времени:** под карточкой поездки — блок «În timp real / După orar»: когда машина будет на остановке посадки (расписание + сообщённая задержка, с пометкой «оценка»), на сколько опаздывает или идёт раньше, сколько остановок до вас, до какого времени выйти из A; если живого прогноза нет — почему (машина ещё на предыдущем рейсе, нет данных, позиция старая, рейс уже проехал — с кнопкой «найти следующий»). Возраст ответа и GPS-точки виден всегда. На карте — машины линии с номером на цвете линии и стрелкой направления; машина вашего рейса крупнее, старые позиции серые с пунктиром. Галочка «Transport în timp real pe hartă» показывает все машины области. Опрос раз в ~15 с только при видимой вкладке (`/api/transit/live`).
- **Как линия ходила на самом деле:** если на сервере настроен Tiger Data, под живой карточкой рейса появляется одна фраза вида «Вчера в это время трамвай 8 шёл на ~3 мин раньше расписания. Будьте на остановке за 4 мин». По нажатию на «откуда это?» раскрываются число рейсов, время, дата и источник. Это наблюдение за недавний день, а не прогноз; совет бывает только «придите раньше» или «может опоздать». Тот же блок есть в версии для телефона. Подробности: `docs/transit-history.md`.
- **Поля «Откуда» и «Куда»:** при наборе — подсказки из `/api/geocode`: улицы, адреса с номером дома, места (факультеты, общежития, кафе, аптеки, парки), остановки с номерами линий. Клавиатура: стрелки, Enter, Esc. Кнопка «Я здесь» берёт геолокацию браузера (на телефоне — только по HTTPS), «⇅» меняет точки местами.
- **Клик по карте** (режим «ставит точки маршрута»): первый клик — точка А, второй — Б. Сервер строит быстрый и более освещённый маршруты. Маркеры можно перетаскивать, карточки переключают маршрут, ссылка `#a=…&b=…&an=…&bn=…` открывает тот же маршрут с теми же подписями.
- **Режим «Почему такой цвет»:** клик по улице показывает свидетельства с источниками и датами: тег OSM, фонари Mapillary, жалобы Sesizări.
- **Слои справа сверху:** велодорожки с освещённостью, остановки с последними рейсами, линии транспорта (из `demo/layers/`), только в пределах области.
- **Ошибки:** точка вне области даёт понятное сообщение с расстоянием до ближайшей дорожки.

## Файлы

| Файл | Что это |
|---|---|
| `web/index.html` | разметка и стили; тексты подставляет `app.js` |

| `web/hist.js` | фраза о том, как линия ходила в недавний день (`historyParts`), общая для этой страницы и `web/m/m.js` |
| `web/vendor/leaflet/` | Leaflet 1.9.4 с лицензией (BSD-2-Clause): страница не зависит от CDN |
| `web/favicon.ico`, `web/favicon.png`, `web/apple-touch-icon.png` | иконка вкладки (16/32/48 px), большая иконка (192 px) и иконка для экрана iPhone (180 px, на белом фоне). Исходник — [Street light icons created by Magnific - Flaticon](https://www.flaticon.com/free-icons/street-light); бесплатная лицензия требует указывать автора, ссылка стоит в подписи карты (`web/app.js`) |

Сервер раздаёт `web/` по адресу `/`, а ссылки на API лежат на `/links`.

## Как удалить

Удалить папку `web/`. Больше ничего менять не обязательно: сервер пропускает отсутствующие папки. Для чистоты можно убрать `("/", ROOT / "web")` из списка папок для раздачи в `backend/app.py`.
