# 15 неочевидных тестов Gemini: фактические результаты

Дата: 15.11.2026, 05:03–05:05 Europe/Bucharest. Актуальный локальный код; сервер Vultr не обновлялся.

**10 прошли сразу, 1 прошёл после подтверждения места, 4 не прошли.** Это результат одного прогона заранее заданных сценариев, не оценка общей точности Gemini.

Выполнено 15 настоящих запросов Gemini. Для сопоставимости один и тот же полученный JSON применён в десктопе `/` и мобильной версии `/m/` (Chrome, 390×844). Во втором интерфейсе генерация не повторялась. `/api/route` в обоих случаях настоящий: проверялись HTTP 200, геометрия, видимые линия и карточки. Два голосовых теста — синтетическая русская речь Milena, PCM WAV 16 кГц, не запись человеческого голоса. Лимиты не отключались; между группами запросов выдерживались паузы.

## Выявленные проблемы

1. **Подмена типа объекта (№11) — высший приоритет.** Библиотека и ректорат — разные места. Нельзя считать маршрут корректным только потому, что `/api/route` ответил 200: координаты A должны соответствовать исходному запросу. Здесь ошибка после транскрипции, при определении места.
2. **Корпуса и филиалы (№4).** Поиск не справился с названием Oituz, хотя нужный объект есть в базе. Уточнение без кандидатов не решает запрос пользователя.
3. **Пространственные условия (№6).** Финальный список кандидатов не гарантированно отфильтрован по отношению к заданному ориентиру. Предыдущий успешный пример про парк не гарантировал обработку других формулировок.
4. **Неподдерживаемые пожелания (№13).** Извлечение только from/to/mode/time теряет дополнительные ограничения. Следует либо реализовать их, либо явно сообщать, что они не применены.

Это не расхождение десктопа и мобильного UI: они одинаково обработали одни и те же ответы. Ошибки №4/6/11 относятся к интерпретации/поиску мест, №13 — к контракту пожеланий и возможностям маршрутизатора.

## Воспроизведение

Набор с ожиданиями до запуска: `scripts/testing/gemini_niche_15.json`.

```bash
TIGER_HISTORY=off .venv/bin/uvicorn backend.app:app --host 127.0.0.1 --port 8019
# In a second terminal, with Playwright on NODE_PATH:
node scripts/testing/check_gemini_niche_15.cjs
```

Нужны Chrome, Playwright, macOS `say` с голосом Milena и ffmpeg для двух аудиосценариев. Скрипт расходует реальную квоту Gemini. Новые результаты и звуковые образцы создаются в уникальной временной папке; приложение и production-настройки не меняются.

Полные ответы `/api/ask`, состояния обоих UI, URL/статусы `/api/route`, время и причины неуспеха сохранены в `docs/testing/gemini-niche-15.results.json`.
