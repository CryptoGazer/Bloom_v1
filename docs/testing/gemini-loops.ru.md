# Gemini: замкнутые прогулки — проверка 15.11.2026

Изменение добавляет `kind: loop` для запросов о круге вокруг центра, парка, здания или текущей позиции. Gemini определяет место, режим и примерный размер; координаты центра проверяются по локальному индексу. Точки обхода подбирает `backend/loops.py` на доступном графе улиц. Оба интерфейса запрашивают существующий `/api/loop` с новым параметром `center`; ручные круги с `points` продолжают работать.

Полный контракт и ограничения: [интеграция Gemini, раздел 5.6](../gemini-ui-integration.ru.md#56-kind-loop-замкнутая-прогулка-вокруг-места). Запущенный backend должен отдавать `ask_version: 3`.

## Результаты

- 246 тестов бэкенда — PASS, в том числе 26 новых проверок loop. Есть проверка замкнутости/непрерывности геометрии, разрешённых улиц, отдельного старта, недопустимого радиуса, выдуманного ID, уточнений, Function Calling и сохранения типа loop.
- 10 тестов мобильной навигации — PASS.
- Старые браузерные регрессии: 7 сценариев десктопа и 9 мобильных — PASS. Текст, запись/WAV, обычный A → B, геолокация, кандидаты, долгий ответ, отмена и ручной круг.
- Новые браузерные проверки: 12 сценариев в каждом интерфейсе — PASS. Gemini подменён фиксированным ответом, маршрутизация настоящая; проверены линии и карточки на экране.
- Живой прогон: 6 запросов к настоящему Gemini. Каждый полученный ответ повторён на мобильной странице; обе версии вызывают настоящий локальный routing API и показывают результат. Все 6 сценариев прошли в обоих интерфейсах.

### Дополнительные сценарии без расхода Gemini

Помимо шести примеров выше проверены:

1. Отдельный старт C12, круг вокруг центра, точная дата/время выхода.
2. Неоднозначный центр: выбор кандидата строит круг без второго запроса Gemini.
3. Центр не найден: выбор места обычным поиском сохраняет тип loop.
4. Неизвестный старт: выбор GPS сохраняет тип loop и указанную позицию старта.
5. Круг на трамвае: явное сообщение о поддержке пешком/велосипеда.
6. Нет места для разумного круга: понятное сообщение, старый маршрут убран.

Для круга вокруг центра дополнительно проверено открытие сохранённой ссылки: восстанавливается круг с теми же точками, а не нулевой A → A.

## Исправления, найденные живым прогоном

Первый голосовой ответ приписал «отсюда» и текущее время без указания человека, а «небольшую» прогулку разобрал как обычный размер. Добавлена проверка опциональных полей по исходной фразе; короткая прогулка без явной численной длины/длительности получает радиус 200 м. «С возвратом к началу» само по себе не задаёт старт. Повторный живой прогон прошёл.

## Повторить

На свежем локальном backend с данными города, например порт 8019:

```bash
TIGER_HISTORY=off .venv/bin/uvicorn backend.app:app --host 127.0.0.1 --port 8019
.venv/bin/python -m pytest backend/tests -q
node --test web/m/nav.test.cjs
node scripts/testing/check_gemini_ui.cjs
node scripts/testing/check_gemini_loops.cjs
node scripts/testing/check_gemini_loops.cjs --live
```

Для браузерных скриптов нужны Playwright и установленный Chrome; если Playwright установлен вне проекта, укажите его каталог `node_modules` через `NODE_PATH`. Для `--live` нужны ключ Gemini в `.env`, `say` с русским голосом Milena и `ffmpeg`. Этот режим расходует квоту; учитывайте лимит 6 пользовательских запросов в минуту. Сгенерированные тестовые аудиофайлы и скриншоты сохраняются во временный каталог, путь выводится при запуске.

Размер прогулки приблизительный: пути по улицам и одностороннее движение могут увеличить расстояние. Радиус ограничен 100–1200 м и может уменьшаться при нехватке покрытия. Полного обхода произвольного района или точного соблюдения километража/длительности функция не гарантирует; фактические значения видны на карточках.
