# Круговая прогулка по точкам на карте — дизайн

Дата: 15.11.2026. Согласовано с пользователем в чате.

## Что делаем

Человек нажимает на карте несколько точек и получает замкнутый маршрут пешком или на велосипеде: 1 → 2 → … → N → снова 1. Порядок обхода — порядок нажатий. Дальше всё как у обычного маршрута: два варианта (самый быстрый и более освещённый круг) с той же анимацией, «Detalii», «Pornește».

## Интерфейс (web/m, система «Тихий свет»)

- **Вход.** На стартовом экране в верхней панели круглая кнопка со значком петли, без подписи (`aria-label`), рядом с языком и легендой.
- **Режим набора точек.** Шторка вместо полей A/B:
  - заголовок «Atingeți harta», после первой точки «Buclă · N puncte»;
  - переключатель Pe jos / Bicicletă (транспорта нет);
  - круглые кнопки «отменить последнюю точку» и «выйти из режима»;
  - основная кнопка «Calculează», неактивна при числе точек меньше двух.
  - Других надписей и примечаний нет.
- **Карта.** Нажатие добавляет точку, не больше 10. Точки с номерами: первая залита белым, как A, остальные с белым контуром. Точки можно перетаскивать. Тонкий серый пунктир соединяет точки по порядку и замыкает круг.
- **Результат.** Экран вариантов: заголовок «Buclă · N puncte», под ним способ и время выхода. Номера точек остаются на карте. Смена способа пересчитывает круг. «Назад» возвращает к набору точек, точки сохраняются.
- **Ссылка.** `#loop=lat,lon;lat,lon;…&m=walk` восстанавливает круг после перезагрузки или смены языка.
- **Навигатор.** Работает по кругу как по обычному маршруту. Положение ищется по ходу маршрута (`nav.js`), поэтому старт не принимается за финиш.

## Сервер

`GET /api/loop?points=lat,lon;lat,lon;…&mode=walk|bike&at=…`

- 2–10 точек. Иначе 422 `bad_points`. Точка вне покрытия — 422 `outside_coverage` с номером точки.
- Каждая точка привязывается к сети улиц выбранного способа.
- Для каждого варианта (самый быстрый, более освещённый) — тот же A* по отрезкам 1→2, …, N→1:
  - сегменты, по которым круг уже прошёл, стоят вдвое дороже, чтобы обратный путь по возможности шёл другими улицами;
  - точки, совпадающие с предыдущей (отрезок короче 1 м), пропускаются.
- Куски всех отрезков склеиваются и суммируются одной функцией `_summarize`: длина, минуты, освещённость, самый длинный тёмный участок, предупреждение, улицы, геометрия.
- Выбор между вариантами — то же правило, что в `Network.plan`. Оно выносится в общую функцию `_verdict`.
- Ответ того же вида, что у `/api/route`: `mode`, `routes`, `verdict`, `at`, `settings`, `data_as_of`, признаки жизни по каждому кругу, плюс `points` (`lat`, `lon`, `snapped`, `snap_m`) и `loop: true`.
- Если нет пути между двумя точками — 404 `no_route`.

## Тесты

На маленькой тестовой сети (квадрат улиц):

- круг начинается и кончается в первой точке, геометрия непрерывна;
- длина круга равна сумме отрезков;
- с двумя точками на противоположных углах квадрата обратный путь идёт другой стороной;
- 1 и 11 точек — 422;
- точка вне покрытия — 422 с номером точки;
- правило выбора одно для `/api/route` и `/api/loop`: существующие тесты маршрутов проходят без изменений.

Страница проверяется в браузере: вход в режим, точки, отмена, перетаскивание, расчёт, смена способа, ссылка после перезагрузки, навигатор в симуляции.
