# План до стоп-кода (UniHack 8, Green Mobility)

Обновлён: суббота 14.11.2026, 15:00. Стоп-код: **воскресенье 15.11.2026, 13:00**. Жюри с 15:00.

## Что мы делаем

Сайт для телефона, работающий в университетском районе и центре Тимишоары (там данные плотные; весь город собирается той же командой, но «нет данных» там 38%). Человек вводит адрес «откуда» и «куда» (или нажимает «я здесь»), выбирает пешком, на велосипеде или пешком с транспортом, и получает два маршрута: быстрый и более освещённый. Каждый участок окрашен по освещённости, есть предупреждения о тёмных кусках и время последнего рейса. Маршрут можно попросить фразой (Gemini) и прослушать голосом (ElevenLabs).

Зачем это Green Mobility: ночью люди берут такси или машину, потому что боятся тёмной дороги. Освещённый путь пешком, на велосипеде или до трамвая делает часть таких поездок «зелёной».

## Где мы сейчас

## Как это устроено

```text
Телефон / браузер (Leaflet, web/)       Бэкенд (Python, FastAPI, backend/)
 ├ карта: районы / улицы на экране ───►  /api/summary, /api/segments   ✅
 ├ клик А и Б → маршрут            ───►  /api/route  (пешком)           ✅
 ├ «почему такой цвет»             ───►  /api/segments/{id}             ✅
 ├ поиск адреса А и Б              ───►  /api/geocode                   ⬜
 ├ «я здесь» (геолокация)          ───►  /api/route                     ⬜
 ├ фраза «от общаги домой…»        ───►  /api/ask    → Gemini           ⬜
 ├ кнопка «прочитать»              ───►  /api/speak  → ElevenLabs       ⬜
 └ пешком + транспорт              ───►  /api/transit (GTFS + живые машины, кеш 15 с)  ⬜
Логгер машин → CSV (scripts/transit/), позже Tiger Data                 ✅ (CSV)
```

Бэкенд нужен по трём причинам: весь город не помещается в браузер; ключи Gemini и ElevenLabs нельзя держать на странице; гайд мэрии требует кешировать городские API на своём сервере.

## Принятые решения

| Вопрос | Решение | Почему |
|---|---|---|
| Стек | Python 3.12 + FastAPI + Leaflet | граф и правила освещённости уже на Python |
| Правила освещённости | `backend/rules.py` (разделы 5–7 спецификации Тимура) | одобрены, проверены на модельном районе; таблица из 18 согласованных случаев в `backend/tests/test_rules.py` |
| План Тимура на 10 задач (`docs/superpowers/plans/`) | целиком не выполняем | нет времени; тесты — на правила, маршруты и API |
| Область карты | университетский район + центр (`config/area.geojson`) | там данные плотные и порог «нет данных» проходит; весь город — 38% без данных |
| Спор жалобы на перекрёстке по названию улицы | не делаем | выигрыш мал, сопоставление названий сложное |
| Почти одинаковые маршруты | одна карточка: быстрый, если освещённый добавляет меньше 5% освещённости и не убирает тёмный кусок длиннее 100 м; освещённый, если он не дольше быстрого больше чем на 30 с | иначе человек видит две одинаковые линии или «+0 мин» |
| Язык страницы | румынский по умолчанию, английский и русский кнопками | требование мэрии: сначала румынский |
| «Оживлённость» | только признаки по пути на время выхода, без оценки и без влияния на выбор маршрута: открытые места в 50 м (часы из OSM), остановки в 100 м с рейсами в ±10 мин, доля пути по главным улицам | часы известны лишь у половины заведений, после полуночи данных почти нет; «нет признаков» = «нет данных» |
| Поиск адресов | свой: реестр улиц мэрии, адреса OSM, заведения, остановки; Nominatim только запасным | у города геокодера нет; Nominatim запрещает подсказки при наборе; адреса людей не уходят наружу |
| Карта | граница области пунктиром; при отдалении — доля известного, при приближении — улицы в окне экрана | область открывается мгновенно |
| Хостинг | Vultr + HTTPS (Caddy) | без HTTPS браузер на телефоне не отдаёт геолокацию |

## Как запустить у себя

Нужно: Python 3.12 и папка `unihack-data/` от Тимура в корне репозитория (в git её нет, передаём архивом). Для работы бэкенда достаточно уже собранных файлов в `data/out/city/`.

**Mac / Linux:**

```bash
./scripts/mac/lightmap.sh setup   # один раз: .venv и зависимости из backend/requirements.txt
./scripts/mac/lightmap.sh api     # сервер на http://localhost:8001
./scripts/mac/lightmap.sh test    # тесты бэкенда
./scripts/mac/lightmap.sh city    # пересобрать освещённость города (нужен unihack-data/, ~1,5 мин)
```

**Windows (Git Bash):** скрипт рассчитан на Mac, поэтому команды напрямую:

```bash
py -3.12 -m venv .venv
.venv/Scripts/python -m pip install -r backend/requirements.txt
.venv/Scripts/python -m uvicorn backend.app:app --port 8001
.venv/Scripts/python -m pytest backend/tests -q
.venv/Scripts/python -I backend/build_city.py      # пересборка города
```

Адреса после запуска:

| Адрес | Что там |
|---|---|
| http://localhost:8001/ | **главная страница** — город, маршрут, «почему такой цвет» |
| http://localhost:8001/docs | все запросы API, можно пробовать в браузере |
| http://localhost:8001/demo/route/ | старое демо маршрута в браузере (только модельный район) |
| http://localhost:8001/data/out/draft-map.html | черновая карта освещённости модельного района |

## Правила, которые нельзя нарушить

- Слова «безопасно» в интерфейсе нет: данных о безопасности у нас нет. Пишем «освещено», «нет данных», «сообщали, что темно».
- «Нет данных» не значит «темно», и показываем это честно.
- Текст и фото жалоб не храним и не показываем.
- Рядом с каждой цифрой источник и дата.
- Запросы к API мэрии: с User-Agent команды, с кешем, без частого опроса.
