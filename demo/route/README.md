# Демо: освещённый маршрут из А в Б

Черновая фича, добавлена 14.11.2026. Человек кликает точку А и точку Б в университетском районе и видит два пешеходных маршрута:

- **быстрый** — самый короткий;
- **более освещённый** — самый короткий, если тёмные участки и участки без данных считать «длиннее».

Каждый участок маршрута окрашен по освещённости. Карточка маршрута показывает время, длину, сколько метров приходится на каждый статус, и предупреждение, если на пути много неподтверждённого освещения.

## Как запустить

```bash
cd ~/Desktop/PABLO/Hackathons/UniHack26/Bloom_v1
python3 demo/route/extract_segments.py     # один раз и после каждой пересборки карты
./scripts/mac/lightmap.sh serve            # локальный сервер на порту 8000
```

Открыть http://localhost:8000/demo/route/

Как пользоваться:
- клик — точка А, второй клик — точка Б, третий клик начинает новый маршрут;
- маркеры А и Б можно перетаскивать;
- нажатие на карточку или на синий пунктир переключает маршруты;
- адрес страницы с `#a=…&b=…` открывает тот же маршрут, его можно отправить человеку для теста. Пример: http://localhost:8000/demo/route/#a=45.74700,21.23950&b=45.74150,21.22000

Страница открывается только через HTTP-сервер: если открыть файл двойным щелчком, сервер тайлов OpenStreetMap не отдаст подложку, а браузер не даст загрузить данные.

## Как это работает

1. `extract_segments.py` достаёт отрезки (геометрия, вид, название, статус освещённости) из черновой карты `data/out/draft-map.html`, а если её нет — из `handoff/preview/draft-map.html`. Результат пишется в `data/out/segments_draft.geojson`, около 1 МБ.
2. `route.js` собирает из отрезков граф: концы отрезков с одинаковыми координатами — один перекрёсток. Маршрут строится только по самой большой связной части сети (98% длины), чтобы точка не попала на изолированный кусок дорожки.
3. Клик привязывается к ближайшей точке ближайшего отрезка. Если до сети дальше 150 м, это «вне зоны демо», маршрут не строится.
4. Алгоритм Дейкстры запускается дважды:
   - быстрый: цена отрезка равна его длине;
   - более освещённый: длина × коэффициент статуса (освещено ×1,0, вероятно ×1,2, нет данных ×1,6, сообщали о темноте ×3,0).
5. Правила показа взяты из раздела 12 спецификации:
   - маршруты совпали — показывается один;
   - освещённый дольше больше чем на 5 минут или на 30% — карточка пишет, что в продукте его скрыли бы;
   - предупреждение появляется, если подряд больше 100 м «сообщали, что темно» или «темно» и «нет данных» вместе занимают больше 20% пути.

**Темнота маршрут не запрещает**, она только делает его дороже. Если к дому ведёт одна тёмная улица, маршрут всё равно дойдёт до точки и честно покажет предупреждение.

Расчёт идёт в браузере, на два маршрута уходит несколько миллисекунд. Бэкенда, ключей и сети, кроме тайлов подложки, не нужно.

## Файлы фичи

| Файл | Что это |
|---|---|
| `demo/route/index.html` | страница: карта и панель |
| `demo/route/route.js` | граф, привязка клика, маршруты, отрисовка; настройки в начале файла |
| `demo/route/extract_segments.py` | выгрузка отрезков из черновой карты |
| `demo/route/README.md` | этот файл |
| `data/out/segments_draft.geojson` | данные для страницы (генерируются) |

Остальной проект фича не меняет.

## Как настроить

Все числа стоят в начале `route.js`: скорость пешком, коэффициенты статусов, пороги показа и предупреждения, радиус «вне зоны». После правки достаточно обновить страницу.

## Как удалить или откатить

```bash
rm -rf demo/route data/out/segments_draft.geojson
```

Больше ничего удалять не нужно.

## Ограничения

- Только модельный район (~3 км², пунктирная рамка) и только пешком: велосипед, транспорт и время суток не учитываются.
- Статусы взяты из черновой карты, то есть из правил спецификации на данных 14.11.2026. Когда придёт папка Тимура, нужно пересобрать карту (`./scripts/mac/lightmap.sh draft <папка>`) и снова запустить `extract_segments.py`.
- Расстояние от точки клика до ближайшей дорожки в расчёт не входит, оно показывается отдельной строкой.
- Коэффициенты статусов — предположение спецификации. Их стоит проверить на людях: «пошли бы вы на N минут дольше ради этого?»
- Интерфейс на русском. Для продукта нужен румынский, затем английский.
